# 無人機足球（對齊 FAI F9A-A）

> 階段一已接上現有 striker 流程：場地尺寸、圓環、起飛區、三局兩勝與計分骨架。
> 預設多人模式是 **striker**（攻擊手穿對方圓環）。`ball`（推一顆漂浮黃球）只在 API 明示 `mode: "ball"` 時才跑，不出現在老師後台或預設開賽。

真實無人機足球裡，每台無人機包在球形護罩裡、自己就是球。只有攻擊手（Striker）能飛穿對方懸空圓環得分。沒有越位、界外、角球、禁區。

---

## 1. 場地

| 項目 | 規格 |
|---|---|
| 長 × 寬 × 高 | **14m × 7m × 5m**（長 = 2 × 寬） |
| 軸向 | 長軸 z（兩門連線）、寬軸 x、中線 z = 0 |
| 地面標線 | 中線＋中心點 |
| 座標 | 藍隊站 −z、攻 +z 門；紅隊相反 |

伺服器以 `SoccerFieldDef` 下發（`halfX` 3.5、`halfZ` 7、`ceil` 5）。單人練習沒有伺服器時用同一套 fallback（`apps/simulator/src/soccer/constants.ts`）。

## 2. 球門圓環

| 項目 | 規格 |
|---|---|
| 內徑 | **70cm**（內半徑 `goalR` = 0.35，穿環判定用這個） |
| 厚度 | **20cm**（管半徑 `goalTube` = 0.10） |
| 外徑 | **110cm**（內徑 + 兩側管厚） |
| 位置 | 離底線往場內 **2m**（門面 `|z|` = 5） |
| 高度 | 圓心離地 **3.25m** |

視覺用的 torus 環心直徑是 0.90m、管厚 0.20m，洞與內半徑對齊。階段一的進球仍看**機體中心**是否在內半徑內，並容許沿 z 約 1m 的穿越帶；整顆護罩都要過洞留給後面。

護罩半徑 0.12m（直徑 24cm，約 20cm 級），小於內半徑，中心才過得了洞；擦到框仍會被擋，所以穿環有難度。機體視覺縮小以落進護罩，不改推力／阻力手感。

## 3. 起飛區

底線中段、寬約 **1m**、進深 1m 的窄帶，兩隊各一條。前鋒居中（x = 0），其餘排在帶內。出生 `|z|` = 6.5。

## 4. 賽制

正規賽一節 **3 分鐘**（測試可送較短 `durationSec`）。

1. **三局兩勝**。每節比分獨立，節末進球多者贏得該局。某隊先得 2 局即結束（可以不打第三局）。三局打完局數不同，局數領先者勝。
2. **局間休息** 15 秒，不另做 3-2-1。開賽仍沿用既有的一次 3-2-1。
3. 三局打完局數相同 → **黃金進球**（時限與一節相同）。先進球者立刻勝。
4. 黃金進球時間到仍 0:0 → **PK 罰球**。藍隊先罰，每次 20 秒，至少各三輪，之後仍平手改驟死。輪到的攻擊手穿對方圓環算一記；時間到沒進換邊。

`ball` 模式維持單節計時，不走三局制。

## 5. 計分（F9A）

- 只有**攻擊手**穿對方圓環才得分。
- 得分後**這一台**須先回到己方半場（過中線）才能再得分。隊友回半場不能替它解鎖。
- 非攻擊手進入**自家**圓環 = 犯規。階段一只公告（`soccer_foul`，reason `own_ring`），不發黃紅牌、不改比分。

## 6. 單人練習

七個 drill（P-1～P-7）仍在，場地與圓環跟上面同一套。P-6 的退半場用過中線。練習不連多人伺服器。
