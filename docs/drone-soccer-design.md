# 無人機足球（對齊 2026 FAI F9A）

> 預設多人模式是 **striker**（攻擊手穿對方圓環），場地用 **F9A-A**。
> `ball`（推一顆漂浮黃球）只在 API 明示 `mode: "ball"` 時才跑，不出現在老師後台或預設開賽。
> F9A-B 是另一組預設，用 `SOCCER_CLASS=F9A-B` 切換；數字與 A 放在同一處。

真實無人機足球裡，每台無人機包在球形護罩裡、自己就是球。只有攻擊手（Striker）能飛穿對方懸空圓環得分。

尺寸只寫兩份、內容相同：

- 伺服器：`apps/api/app/games/soccer_presets.py`（下發 `field`，含 `shieldR`）
- 客戶端 fallback／單人練習：`apps/simulator/src/soccer/constants.ts`

`SoccerField` 不再自帶另一組預設數字。

---

## 1. 場地（F9A.2.2）

| 子類 | 長 × 寬 × 高 |
|---|---|
| **F9A-A**（預設） | **14 m × 7 m × 5 m** |
| F9A-B | **6 m × 3 m × 3 m** |

長 = 2 × 寬。長軸 z（兩門連線）、寬軸 x、中線 z = 0。藍隊站 −z、攻 +z 門；紅隊相反。

伺服器以 `SoccerFieldDef` 下發（A：`halfX` 3.5、`halfZ` 7、`ceil` 5）。單人練習沒有伺服器時用同一套 F9A-A。

## 2. 球門圓環與護罩

### F9A-A（F9A.3.1、F9A.1.1、WDSC 1.4.2）

| 項目 | 規格 |
|---|---|
| 內徑 | **60 cm**（內半徑 `goalR` = 0.30，穿環判定用這個） |
| 厚度 | **20 cm**（管半徑 `goalTube` = 0.10；F9A.3.1 的 T 上限，與徑向跨距相同） |
| 外徑 | **100 cm**（外半徑 0.50） |
| 位置 | 離底線往場內 **1.5 m**（門面 `|z|` = 5.5） |
| 高度 | 內圈底部 **3 m**，圓心 **3.30 m** |

2026 V2 **F9A.3.2** 把「A 離底線 1.5 m、B 離底線 1 m」和「離地 2 m 到內圈底部」寫在同一句，讀起來分不出高度是只給 B，還是 A、B 都是 2 m。這裡採 **2025 WDSC 1.4.2**：F9A-A 內圈底部 3 m、F9A-B 內圈底部 2 m。圓心 = 底部 + 內半徑，所以 A 的圓心是 3.30 m。

護罩直徑 **40 cm**（半徑 `shieldR` / `SOCCER_BALL_R` = 0.20；F9A.1.1：40 cm +2 cm，必須塞進直徑 42 cm 的圓）。小於內半徑，中心才過得了洞；擦到框仍會被擋。

視覺 torus 的環心直徑是 0.80 m、管厚 0.20 m，外緣 1.00 m，洞與內半徑對齊。進球看整顆護罩有沒有過洞，不只看球心。

### F9A-B（同一處預設，預設不開）

| 項目 | 規格 |
|---|---|
| 場地 | 6 × 3 × 3 m |
| 內半徑 | **0.20**（內徑 40 cm） |
| 外半徑 | **0.35**（外徑 70 cm） |
| 厚度 T | 條文上限 **10 cm**。建議外徑與內徑的徑向跨距是 15 cm，大於 T 上限。視覺圓管填滿內緣到外緣，管半徑 0.075，畫出來的外緣才是 0.35 |
| 位置 | 離底線 **1 m**（門面 `|z|` = 2） |
| 高度 | 內圈底部 **2 m**，圓心 **2.20 m** |
| 護罩 | 半徑 **0.10**（直徑 20 cm，F9A.1.1） |

## 3. 起飛區

底線中段、寬約 **1 m**、進深 1 m 的窄帶，兩隊各一條。前鋒居中（x = 0），其餘排在帶內。F9A-A 出生 `|z|` = 6.5。起飛區人數這次不改。

## 4. 賽制

正規賽一節 **3 分鐘**（測試可送較短 `durationSec`）。

1. **三局兩勝**。每節比分獨立，節末進球多者贏得該局。某隊先得 2 局即結束（可以不打第三局）。三局打完局數不同，局數領先者勝。
2. **局間休息** 15 秒，不另做 3-2-1。開賽是起槳再接一次 3-2-1，倒數期間鎖控。
3. 三局打完局數相同 → **黃金進球**（時限與一節相同）。先進球者立刻勝。
4. 黃金進球時間到仍 0:0 → **PK 罰球**。藍隊先罰，每次 20 秒，至少各三輪，之後仍平手改驟死。輪到的攻擊手穿對方圓環算一記；時間到沒進換邊。

`ball` 模式維持單節計時，不走三局制。

## 5. 計分（F9A.8.4）

- 只有**攻擊手**穿對方圓環才得分。
- 得分後**這一台**須先回到己方半場（過中線）才能再得分。隊友回半場不能替它解鎖。
- 非攻擊手進入**自家**圓環 = 犯規，接著罰球。
- 穿環看**整顆護罩**有沒有沿行進方向過去：後緣跨過門面時，球心必須在內半徑減掉護罩半徑（F9A-A：0.30 − 0.20 = 0.10）裡。不看機頭朝向，球心擦到框不算。伺服器用位置軌跡自己重算，客戶端只報 `soccer_goal` 不夠。

## 5.1 手感、開賽、罰球、罰牌

| 項目 | 規格 |
|---|---|
| 手感 | 新手最大傾角 18°、模擬 30°、專業 42°。鬆桿自動回正：新手強、專業弱。水平推力跟 sin(傾角) 走，專業滿舵才是原本滿推力 |
| 開賽 | 起槳後 3-2-1。倒數鎖控。已在起飛點報到又離開 = 搶跑 |
| 罰球 | 10 秒（F9A.9.1）。犯規隊的對方攻擊手，對犯規隊一名防守。節時鐘先暫停 |
| 罰球何時出現 | 搶跑、得分後又往對方圓環穿而還沒回己方半場、非攻擊手進自家圓環 |
| 碰撞 | 機對機半徑 = 護罩。F9A-A 為 0.20 m，互推並輕微反彈。牆面同樣輕彈，不把速度夾成 0 |
| 空中接近速度牌 | **預設關閉**。2026 F9A.9 沒有「飛在空中、沿法線接近太快就黃牌／紅牌」。程式留著，`SOCCER_AIR_CONTACT_CARDS=1` 才當教學選項打開 |
| 墜機 | 下降速度夠大撞地。該機本局紅牌排除。這條不是接近速度規則，維持不變 |

## 6. 單人練習

七個 drill（P-1～P-7）仍在，場地與圓環跟 F9A-A fallback 同一份。P-6 的退半場用過中線。練習不連多人伺服器。
